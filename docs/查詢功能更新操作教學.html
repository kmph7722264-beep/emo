1
更新並重新部署 Google Apps Script
讓後端支援新的「查詢訂單」和「取得問卷連結」功能
  1. 用瀏覽器開啟 script.google.com，登入後點開 EMO 專案。
  2. 將 C:\emo\gas\Code.gs 的全部內容複製（Ctrl+A → Ctrl+C）。
  3. 在 Apps Script 編輯器中，選取全部程式碼（Ctrl+A）→ 貼上（Ctrl+V）。
  4. 點上方 💾 儲存（Ctrl+S）。
  5. 點右上角 部署 ▾ → 選「管理部署作業」。
  6. 找到現有的部署項目，點右側 ✏️ 編輯 圖示。
  7. 「版本」選 新版本（下拉選單選「建立新版本」）。
  8. 點 部署，完成後複製 /exec 網址（不需修改，和之前相同）。
✅
部署後可在 Apps Script 執行紀錄確認沒有錯誤，表示更新成功。
⚠️
必須選「新版本」才會生效。若只按儲存而不重新部署，新功能不會上線。
2
在 LINE Developers 建立兩個新 LIFF App
menu.html 和 myorders.html 各需一個獨立 LIFF ID
  1. 開啟 developers.line.biz → 選您的 Provider → 點 Login Channel（就是 EMO 的登入 Channel）。
  2. 上方選單點 LIFF → 右上角點 Add。
  3. 依下表建立 第一個（每日菜單）：
    欄位填入值
    LIFF app nameEMO每日菜單
    SizeFull
    Endpoint URL您的 menu.html 網址（HTTPS）
    Scopes勾選 profile
    Scan QR不需開啟
    點 Add → 複製出現的 LIFF ID（格式：1234567890-xxxxxxxx）。
  4. 再點一次 Add，建立 第二個（我的訂單）：
    欄位填入值
    LIFF app nameEMO我的訂單
    SizeFull
    Endpoint URL您的 myorders.html 網址（HTTPS）
    Scopes勾選 profile
    點 Add → 複製第二個 LIFF ID。
💡
LIFF ID 格式像 2010095803-AbCdEfGh。
建立後在 LIFF 列表可隨時回來複製。
3
填入 LIFF ID，上傳兩支新頁面
編輯 menu.html 和 myorders.html，把剛才的 LIFF ID 填進去

修改 menu.html

  1. 用記事本開啟 C:\emo\liff\menu.html。
  2. 找到第 2 行 const LIFF_ID，把引號內的 ID 改成「每日菜單」的 LIFF ID：
// 改這一行（menu.html） const LIFF_ID = '填入 EMO每日菜單 的 LIFF ID';

修改 myorders.html

  1. 用記事本開啟 C:\emo\liff\myorders.html。
  2. 同樣找到 const LIFF_ID，改為「我的訂單」的 LIFF ID：
// 改這一行（myorders.html） const LIFF_ID = '填入 EMO我的訂單 的 LIFF ID';

上傳到您的主機

  1. 將修改好的兩個檔案，和原有的 style.css，一起上傳到您的靜態主機（GitHub Pages / Netlify / 自架伺服器皆可），放在和其他 LIFF 頁面相同的目錄下。
⚠️
網址必須是 HTTPS，否則 LINE LIFF 無法載入頁面。
💡
上傳後可直接在瀏覽器輸入 https://您的網址/menu.html 預覽，確認頁面正常顯示（非 LIFF 環境菜單仍可載入，但「前往訂餐」可能需 LINE 才能跳轉）。
4
更新 LINE 圖文選單的按鈕連結
讓 6 宮格的格 3、格 4、格 5 指向新頁面
  1. 開啟 manager.line.biz → 選 EMO 官方帳號。
  2. 左側選單 → 聊天室相關功能 → 圖文選單。
  3. 找到 EMO 選單，點 編輯。
  4. 依下表更新各格的「動作 → 連結」：
格子功能動作連結說明
格 3（右上） 每日菜單 https://liff.line.me/
[每日菜單 LIFF ID]		 開啟 menu.html
格 4（左下） 訂單查詢 https://liff.line.me/
[我的訂單 LIFF ID]		 開啟 myorders.html
格 5（中下） 用餐回饋問卷 https://liff.line.me/
[我的訂單 LIFF ID]?survey=1		 直接開啟待填問卷
💡
格 5「用餐回饋問卷」和格 4「訂單查詢」使用同一個 myorders.html，差別是格 5 的網址後面加了 ?survey=1，頁面會自動切換到「待填問卷」分頁。
  1. 三格都更新完後，點右上角 儲存並發布。
5
手機測試三項功能
確認每個按鈕正常運作
  1. 每日菜單：點圖文選單「每日菜單」格
    → 應顯示今日早/中/晚餐名稱與剩餘份數
    → 點「🛒 前往訂餐」應跳轉至訂單頁
  2. 訂單查詢：點「訂單查詢」格
    → 應顯示您的歷史訂單（含領餐狀態）
    → 若無訂單紀錄，顯示「尚無訂單紀錄」
  3. 用餐回饋問卷：點「用餐回饋問卷」格
    → 自動切到「待填問卷」分頁
    → 點「📝 填寫用餐回饋問卷」→ 應跳轉至問卷頁
🎉
三項功能全部正常即完成！問卷連結需要後端 LIFF_SURVEY_URL 屬性已設定，若顯示「問卷功能尚未啟用」請聯絡管理員確認 Apps Script 屬性。
⚠️
常見問題排查：
  • 頁面顯示「LIFF 初始化失敗」→ 確認 LIFF App 的 Endpoint URL 正確且已上傳
  • 菜單顯示「尚未設定」→ 確認 GAS 的 Menu 工作表已填入當日菜單
  • 訂單頁顯示空白 → 確認 GAS 重新部署成功（Step 1）
  • 問卷按鈕跳「無法取得他人訂單」→ 確認 LIFF ID 填對（每個頁面用自己的 LIFF ID）
