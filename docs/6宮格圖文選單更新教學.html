1
開啟設定檔，修改文字
檔案位置：C:\emo\make_richmenu.py
  1. 用記事本或 VS Code 開啟 C:\emo\make_richmenu.py
  2. 找到第 25 行附近的 CELLS 區塊，這裡就是 6 格的內容設定：
# 格式：("大標題", "副標說明", ...) CELLS = [ ("線上訂單", "掃碼立即點餐", ...), ("現場用餐", "掃描點餐單QR購餐",...), ("每日菜單", "今日菜色一覽", ...), ("訂單查詢", "查看我的訂單", ...), ("用餐回饋問卷", "分享您的體驗", ...), ("管理入口", "後台管理系統", ...), ]
💡
只需修改引號內的文字，第一個是大標題，第二個是副標說明。
例如把 "今日菜色一覽" 改成 "點選查看今日餐點" 即可。
格子大標題（不建議改）副標說明（可自由修改）
格 1（左上）線上訂單掃碼立即點餐
格 2（中上）現場用餐掃描點餐單QR購餐
格 3（右上）每日菜單今日菜色一覽
格 4（左下）訂單查詢查看我的訂單
格 5（中下）用餐回饋問卷分享您的體驗
格 6（右下）管理入口後台管理系統
⚠️
副標說明建議 8 個字以內，超過太長可能顯示不全。
  • 修改完成後，儲存檔案（Ctrl + S）。
    • 2
    執行程式，重新生成圖片
    需要電腦已安裝 Python 與 Pillow
    1. 在 C:\emo 資料夾空白處，按住 Shift + 右鍵，選「在這裡開啟 PowerShell 視窗」（或「命令提示字元」）
    2. 輸入以下指令，按 Enter：
    python make_richmenu.py
    1. 看到畫面出現以下訊息，代表成功：
    Done: C:/emo/EMO_richmenu_6grid.png
    ✅
    新圖片已儲存在 C:\emo\EMO_richmenu_6grid.png，可以雙擊預覽確認文字是否正確。
    ⚠️
    若出現 ModuleNotFoundError: No module named 'PIL'，請先執行：
    pip install Pillow，再重新執行步驟 2。
    3
    登入 LINE，更新圖文選單圖片
    在電腦瀏覽器操作（建議使用 Chrome）
    1. 用瀏覽器開啟 LINE Official Account Manager：
      https://manager.line.biz
      用您的 LINE 帳號登入。
    2. 從左側選單點選您的 EMO 官方帳號。
    3. 點左側 「聊天室相關功能」→「圖文選單」。
    4. 找到已建立的 EMO 選單，點右側 編輯 按鈕。
    5. 點選「圖片」區域，再點 變更圖片。
    6. 選擇剛剛生成的新圖片：
      C:\emo\EMO_richmenu_6grid.png
    7. 圖片上傳完成後，點右上角 儲存並發布。
    💡
    若沒有「編輯」按鈕，表示選單尚未建立，請參考《LINE圖文選單設定教學.md》完整建立流程。
    4
    手機確認更新成功
    約 1–2 分鐘內生效
    1. 打開手機 LINE，進入 雄好築軒智慧用餐 對話視窗。
    2. 下方圖文選單應已顯示新的圖片，確認文字是否正確。
    3. 若還顯示舊圖：下拉聊天畫面重新整理，或關閉 LINE 後重新開啟。
